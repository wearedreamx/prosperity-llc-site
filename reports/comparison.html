Design Observations

Manual notes on each firm's site design, gathered while researching modernization direction. Not automated — recorded by eye. Split into what worked and what didn't per firm; firms marked Blend Candidate are the strongest reference points for Prosperity's own style — closest to the target look with the fewest liabilities to avoid inheriting.

  • PwC

    Good

    • Simple, disciplined color palette with a single clear accent color
    • Subtle, clean animations

    Bad

    • Too square/rigid overall — could use softer geometric shapes as separators
    • Animations could be smoother and more dynamic

  • EY

    Good

    • Clean, slightly darker theme (dark grey as a main color)
    • Good asset quality; lightly animated, clean overall

    Bad

    • Imagery feels generic — stock-photo quality
    • Same squarish, stacked template as PwC, just with larger assets

  • KPMG

    Good

    • None noted — weakest of the four

    Bad

    • Poor-quality stock assets — flat color blocks with shapes rather than real imagery
    • Layout feels disjointed/all over the place
    • Animations are stiff, not smooth
    • Body text runs a bit too small
  • Blend Candidate

    Deloitte

    Good

    • Large, spaced-out assets — not content-dense
    • Only one of the four using rounded shapes instead of straight/square assets
    • Only one with autoplaying video; animations are smooth

    Bad

    • Palette uses too many colors
    • Leans on brand name/status rather than explaining what they actually do — a luxury Prosperity doesn't have and shouldn't copy

  • General note — category style

    The Big Four's shared look (squarish/stacked blocks, restrained palette, stock imagery of professionals, subtle scroll animation) is a recognizable, near-universal style sometimes called "corporate minimalism" or the "Big Four house style" — common across large B2B/professional-services firms aiming to look safe and enterprise-credible rather than distinctive. Notably, this is different from the more colorful, animation/tech-heavy style used by firms like Salesforce, Deloitte Digital, or Accenture — that more vibrant "tech-forward" look is a deliberate departure from the plain corporate-minimalist default, not the same category. Worth deciding early whether Prosperity should blend into the safe/credible corporate-minimalist convention, or deliberately depart from it the way those tech-forward firms did.

    CBIZ

    Good

    • Closest style match to Prosperity's current site, but meaningfully more polished
    • More dynamic, smoother animations; better blending between sections
    • Rounded corners instead of hard edges
    • Larger assets, big hero banners done well

    Bad

    • No real liabilities noted — the strongest direct benchmark found so far

  • Grant Thornton

    Good

    • Uniform, purple-leaning color theme, reminiscent of Deloitte
    • Everything below the hero is clean, with very smooth animations

    Bad

    • Very large hero right off the bat, but low-quality, uninformative footage — a higher-quality clip would've worked better
    • Oversized hero actively hinders navigation — extremely frustrating

  • RSM US

    Good

    • Fairly condensed but readable
    • Very good, inviting use of color
    • Very responsive site

    Bad

    • Squarish, stacked, "imbricked" (overlapping/shingled) design — same category convention again
    • Animations are serviceable but unimpressive
    • Imagery used mainly for its color value — doesn't carry much informational weight on its own
  • Blend Candidate

    Aprio

    Good

    • Same disciplined-palette approach as PwC — simple palette with a distinct orange accent color
    • Terminal/monospace-style font — minimalist but effective, and gives it a bit of a distinct identity versus the Big Four sameness
    • Lightly animated and clean

    Bad

    • No real liabilities noted yet

  • Citrin Cooperman

    Good

    • Good use of color

    Bad

    • Compact, with barely any imagery/assets
    • Uses click-to-reveal panels instead of a vertical stacked layout to surface more content — feels a bit dated
    • Barely any animation — feels stiff
    • Too text-dense — poor spacing and asset-to-text ratio, content feels condensed rather than given room to breathe
  • Current State — Prosperity Partners

    Prosperity Partners (Prosperityllc.com)

    Good

    • Clean and professional overall, serviceable — not broken, just not polished/slick
    • Disciplined color palette (white, one primary blue, one lighter accent blue) — this part isn't the problem
    • Culture section uses real staff photography, not generic stock images — an authentic strength worth keeping
    • Footer lists all 10 physical offices — a real trust signal showing genuine scale

    Bad

    • Flat type scale — 176 of ~225 text elements on the homepage are exactly 16px, with almost no size variation to create visual hierarchy
    • Unresolved square/circle mismatch: every button is a hard 0px-radius rectangle, while the values-section icons are 100%-radius circles — nothing in between, no consistent "rounded" language tying the two together
    • No real icon system — 0 of 15 homepage media elements are true icons; the only icon-like elements are raster PNGs, not a cohesive set
    • Zero real motion design — no CSS animations anywhere on the homepage, only generic inherited hover transitions
    • Achievement badges are visually inconsistent — four awards, four different ad-hoc graphic treatments (ribbon badges, a certificate image, a black card), reading like the KPMG "flat shapes standing in for real design" issue
    • Values section uses an alternating left/right zigzag icon-timeline layout — a distinctly ~2016–2019-era pattern, a dated tell on its own separate from the icons themselves
    • "What's New" card grid mixes real staff photos with scanned certificates/logos — inconsistent image treatment within the same grid
    • Full contact form (name/email/phone/message + visible reCAPTCHA) embedded directly on the homepage, rather than a clean CTA button linking to a dedicated contact page — reads as a small local-business template convention rather than an enterprise-credible firm, and clutters the page's ending instead of closing on a confident final CTA
